# ProjectOne RP Loading Screen

A custom FiveM loading screen for ProjectOne RP.

## Features

- Neon blue, purple, and pink design
- FiveM loading progress and connection status
- Desktop-focused layout
- Google Font: Rajdhani

## Preview
You can view the [loading screen here](https://prnt.sc/aCAlIMpfH_mS).

## Installation

ensure the resource in your server configuration:

```cfg
ensure fgs-loading
```

The fonts are loaded from Google Fonts.

## Usage

Free to use, modify, and share in your FiveM server.
